# dicom-till-3d

Teknisk 3D-rekonstruktion av föremål från DICOM-data, exempelvis från DT-skanningar.

Målet är att läsa och bearbeta DICOM-data lokalt i webbläsaren och skapa 3D-modeller som kan exporteras som STL.

## Ursprung och erkännande

Projektet är planerat att bygga vidare på [DicomDrift](https://github.com/MenzelRobin/DicomDrift) av Robin Menzel. DicomDrift är tillgängligt under MIT-licensen.

Tack till Robin Menzel för det öppna källkodsprojektet. Ursprunglig upphovsrättsnotis och licensvillkor finns i [LICENSE](LICENSE).
